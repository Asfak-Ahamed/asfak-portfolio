# Asfak Ahamed — React Portfolio

A responsive React + Vite portfolio rebuilt from the supplied portfolio and updated with the supplied CV.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Resume is included at `public/Asfak_Ahamed_CV.pdf`.
- Project GitHub/live-demo URLs are intentionally not invented; add them in `src/main.jsx` when available.
- Contact links use the email, phone and LinkedIn information supplied in the CV.
